# Referencias visuales

Guarda aquí capturas (`.png`/`.jpg`) de apps cuyo diseño te guste. Una imagen orienta a Claude mucho más que diez adjetivos.

## Qué capturar (5–10 en total)
- **Formularios de creación**: crear tarea/proyecto/hábito en otras apps. Es lo que más importa ahora.
- **Listas de tareas** y vista "Hoy".
- **Detalles** que te gusten: un botón, un selector de fecha, un menú, una animación (graba un GIF si puedes).

## Dónde mirar
- Apps: Linear, Things 3, Todoist, TickTick, Raycast, Height, Sunsama, Akiflow, Notion.
- Galerías: mobbin.com (pantallas reales de apps), dribbble.com, land-book.com.

## Nombre de archivo
`origen-que-muestra.png`, p. ej. `linear-crear-issue.png`, `things-vista-hoy.png`.
